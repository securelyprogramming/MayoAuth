# Security reports

Please do not put credentials, exploit details or customer information in public
issues. Use GitHub's private vulnerability-reporting feature when enabled on this
repository. If it is unavailable, open a public issue requesting a private contact
channel without describing the vulnerability. No response SLA is offered in beta.

Use only synthetic/non-sensitive accounts until independent review and the
deployment's recovery/backup controls are in place. Core authentication fixes
belong in the public Community engine.
